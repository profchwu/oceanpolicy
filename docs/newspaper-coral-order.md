# Newspaper edition and coral-first order

New sessions use `missionOrder: reef-grass-wind`: coral → seagrass → wind. Version 39 sessions with `reef-wind-grass` retain coral → wind → seagrass. The first chronological level supplies the pilot baseline, and the following two levels supply the pilot follow-up average. These different topics are not validated equivalent tests.

Sessions without this marker retain the original wind → seagrass → coral order. The validator preserves the marker in the synchronized record, and event mission IDs, scene IDs, environmental values, goals, reports and downloadable data resolve the same order. Researchers should separate these orders when comparing cohorts; existing summary formulas do not stratify by order.

The bilingual news entry uses a paper-colored surface, serif masthead, ruled edition/date strip, prominent headline, illustrated photograph with an AI label, source link and policy assignment. Small displays use reading-page controls rather than document scrolling. Existing source dates and factual summaries are unchanged.
