# Generated environment states

Six built-in image_gen edits were generated from the existing reef, seagrass and wind backgrounds. Original raster files are retained in `public/environment-states/`; exact prompts are saved in `environment-art-prompts.json`. No Python image processing or substituted vector illustrations were used to create these assets.

`EnvironmentArtwork` draws the generated low/high variants only within geographic masks. Water condition uses metric 1, habitat/coral/seagrass uses metric 2, and wind-village power uses metric 0. Each independent blend weight is clamped value/100; this continuous visual mapping is a teaching convention, not a calibrated environmental model. The two endpoint images interpolate intermediate conditions, so small numeric changes are gradual rather than abrupt threshold swaps. Actual five-second model values drive the images throughout animation and remain in the finished scene. Zero does not imply ecological extinction; 100 does not imply complete recovery. The improved reef asset deliberately retains pale stressed patches. Local water treatment never changes the external heat-event state.

The original island terrain remains fixed behind localized raster layers. Oversized schematic coral/seagrass and replacement cartoon houses were removed from this view. Policy-specific construction, cable faults, population and ocean motion remain separate layers. News pictures and their captions are unchanged.

Validation: six assets present, reference-height framing, bounded blend weights and independent metric mapping, existing policy/response route checks and numerical reconciliation. Browser contact sheet compared all three scenes at teaching indices 20 and 80; game test verified changing water values bind directly to the new artwork without a selection panel blocking the animation. The generated images are illustrative rather than measurements, and scene movement remains ambience rather than scored evidence.
