# Single-screen news edition

The three bilingual news adaptations now provide event facts, environmental/policy context and a separately labelled fictional policy task. They are editorial summaries, not reproductions of the original articles. Source reports were checked on 2026-10-16:

- Coral: https://www.nesdis.noaa.gov/news/worlds-fourth-mass-coral-bleaching-event-likely-ended-2025 (2026-06-02).
- Seagrass: https://enews.moenv.gov.tw/moenv-news/zh-tw/News/2278 (2025-07-24).
- Wind: https://service.moea.gov.tw/EE514/tw/geipc/155-7446.html (2026-03-27).

News no longer uses reading-page controls. The masthead, dated headline, illustration, full adaptation and source remain together. A separate study-code dialog opens after reading, before the first mission starts. Existing ID validation, policy flow, order and scoring are unchanged. Short phone layouts prioritize the full article; the numeric goal is also shown in the game after entry.

Checked desktop 1280×720, portrait 390×844 and 375×667, and landscape 844×390. Bilingual content and short-screen overlap were reviewed using an isolated UI build with cloud writes disabled. The study-code-to-first-mission transition was exercised. This news content changes the learning exposure, so research protocols should identify the edition used.
